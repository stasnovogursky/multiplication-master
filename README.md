# Multiplication Master — веб-гра для вивчення таблиці множення

Веб-додаток на Vue 3 + Vite. Три таблиці: «Число 1», «Число 2», «Результат».
Дитина обирає число зліва, число справа, і шукає відповідь у третій таблиці.

Правила гри:
- Обидва обрані числа і правильна відповідь підсвічуються ОДНАКОВИМ кольором.
- Якщо відповідь правильна — число зникає з таблиці результатів (+зірка, конфеті, звук).
  Поступово вся таблиця результатів «розбирається» — наочний прогрес.
- Якщо неправильно — комірка тремтить (червона), у статистиці з'являється ❌.
  Обчислення НЕ показується одразу — дитина має відповісти сама (зв'язок «числа → результат»).
- Повторно розв'язувати вже вивчений приклад не можна — щоб не закріплювати ті самі пари.
- ⚙️ «Рівні» — вибір таблиць (2…9) у налаштуваннях; «🔄 Спочатку» — скидає гру.

Команди:
  npm install        # встановити залежності
  npm run dev        # dev-сервер (для розробки)
  npm test           # юніт-тести (vitest, 9 тестів)
  npm run build      # продакшн-збірка у dist/

Хостинг на nginx: див. deploy/nginx-multiplication.conf
